# FCC 影子查询、采集与故障演练（隔离评审）

本轮不允许生产变更：所有DDL/DML仅在临时本地PostgreSQL 17及内部Docker网络的隔离PostgREST 13运行；数据和JWT均为合成值，测试不调用真实FCC或生产数据库。上轮双遍516条真实验收是时点证据。本轮产物为 `sql/review` 草案、采集代码和测试，不能直接部署。

## 已提交版本查询

`fcc_shadow_open()` 返回当前已提交run_id及数量；`fcc_shadow_page(version,after_id,limit,status)` 必须显式带committed版本，按真实bigint数值升序游标分页，返回ID十进制字符串；允许状态scheduled/cancelled/postponed/rescheduled/movedOnline，limit 1–500。`fcc_shadow_detail(version,id)` 返回相同的安全字段投影（detail原文为null），不存在则返回null。prepared、processing、aborted或未知version拒绝；所有接口service_role专用，旧客户端与旧RPC未切换。

打开版本与随后的每页/详情必须使用同一run_id。发布新版本时事务提交前其他连接仍看到旧指针；提交后open返回新版本，已固定旧版本的分页仍读旧版本，不混合两个FCC版本。保存旧版的期限、回滚后旧版访问权限、游标签名/过期与清理策略尚未设计；目前任何已提交版本可被有权service_role读取。影子stage禁止UPDATE/DELETE，提交再核对内容及UUID摘要，但DB owner/超级用户可修改或禁用保护，不能当作防篡改归档。

历史共存建议：旧表单独读、FCC固定版本单独读，结果按显式来源和内部ID标识，再由受控服务合并；**不能仅按名称日期去重**。32条旧记录本轮未被修改或自动关联；没有实现人工确认绑定、跨两源一致快照或历史表数据冻结，旧表在分页期间可能变化。任何同一实体的合并展示须等待审核决定和版本化绑定。不能把它视为目前已交付的生产查询。

## 可信采集与数据库的边界

`collectAndPrepare` 使用现有 `fetchFccSnapshot`，固定FCC来源、默认每页20、原超时和页数限制；观察两遍分页，分别核实页序/总数/页面长度、逐条规范化、UUID唯一性与两遍内容一致。取得实际两次采集数组后做U+0000预检，再由进程生成run_id，将两遍提交数据库；数据库再次排序、比较、计算UUID与JSONB内容SHA-256，返回回执；进程核对总数和UUID摘要，并分别记录其JSON序列化内容摘要与DB JSONB规范化摘要（两者编码不同，不能直接比较）。单遍采集完成和两遍一致是不同证据；返回材料包含两遍页数、数量、时间、run_id、集合摘要及双方内容摘要，不包含token或活动详情。

批次引擎默认仅将prepare权限授予隔离 `fcc_review_collector`，`fcc_trusted_collection.sql` 再次撤销通用ingest角色的prepare权限以强化这一边界；批次处理仍由ingest角色负责。外部普通调用方不能直接用自报total/证明标志通过该入口，但**任何能取得collector数据库角色或控制其签名/执行环境的人仍可传造假的数组**，数据库无法独立证明网络来源或两遍独立性。采集代码允许依赖注入fetch以离线测试，正式环境必须把fetch实现与prepare能力固定在可信进程中，禁止作为外部参数暴露；部署、角色发放、访问控制、审计证据保管与来源认证均尚未实现。不存在密码学远程来源证明，也不能声称已实现无信任证明。

U+0000在PostgreSQL JSONB解析前无法由数据库函数生成路径；采集器在prepare前调用本地预检，拒绝并给出脱敏路径，测试不打印原文。不能将该辅助工具视为对其他可绕过采集器的数据库输入路径的保护。状态未知、null/空和URL安全策略仍依赖现有适配器及SQL边界；源快照没有数据库事务游标，双遍相等不等同全程原子快照。

## 合成故障与性能（一次本地观测，不是生产SLA）

- 516条、20条/页，模拟FCC网络52次请求（两遍各26），预览/快照准备含校验；模拟网络断链、超时及两遍数据漂移时prepare回调均未调用。
- 临时PG事务开始后处理批次，随后向合成Node写入进程发送SIGKILL，数据库连接断开并回滚，回执为0，再以同run恢复；这是真实杀死本地测试进程，但不是杀死数据库或Supabase容器。重复提交、错误摘要、冻结和双run竞争由既有隔离批次测试覆盖。
- 最新观察：采集加prepare约132.66 ms（其中prepare事务34.35 ms）；6批分别约5.65、4.63、3.78、3.92、3.33、1.13 ms；提交约8.47 ms；SIGKILL后检查、6批恢复到提交约32.29 ms；7次游标页查询共21.31 ms。人工持有gate锁150 ms，关闭观察到约152.31 ms等待。数据为本机小型合成测试，不含真实FCC网络延迟、生产PostgREST、磁盘压力或Supabase吞吐，不能外推上线容量。
- 通过发布事务未提交时读取、提交后读取两次检查，固定旧version结果仍一致；该测试未覆盖多进程大规模并发、跨区域、数据库故障切主或真实网络分区。

## 下一阶段阻断项

本轮可以审查隔离原型与故障证据，但不能进入生产：可信collector身份与证据链部署尚未设计，人工审核的历史绑定/冲突未实现，影子与历史并存读取尚未集成，详情和媒体/客户端兼容未完成，现有旧RPC/RLS/旧写入排空与服务角色权限未完成。需要隔离环境的数据库进程崩溃、真实HTTP断链、复原与并发压测和生产约束评审；所有生产迁移、部署或写入均仍需用户再次明确授权。
